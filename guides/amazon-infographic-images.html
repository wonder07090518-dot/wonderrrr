What to put on Amazon infographic (secondary) images

A useful secondary image answers one buyer question at a glance. A shopper may already know what the product looks like from the MAIN image; the following images can explain a feature, show scale or clarify what is included. Plan each image around information you can verify and a photograph that represents the actual item.

Amazon image requirements can differ by marketplace and category. Check the current Seller Central image guidance and your category style guide before publishing. Secondary-image examples here are planning ideas, not permission to use a particular claim or badge.

Give each image one job

List the questions a customer needs answered before choosing the product. For a storage basket, those might include its dimensions, material, handles and contents. Assign one primary message to each image instead of trying to put the full product description on every slide. A short heading can name the answer, while a photo or simple diagram supplies the evidence.

  • Show a feature in context: a close view of a handle can explain how it is attached.
  • Use a dimensions image to help a buyer check fit before ordering.
  • Show the actual contents together when a set includes several pieces, with a clear count.
  • Use a detail view for texture or construction, keeping the scale and material honest.

Choose an order that moves from the most useful question to supporting details. Avoid repeating the same benefit with different words. If a message needs a paragraph of fine print to make it accurate, simplify it or leave it for the listing description.

Make text readable on a phone

Start with a large, legible typeface and strong contrast against the background. Keep a heading short, use ordinary words and give each callout enough empty space. Place text where it does not cover the product’s defining features. Thin lines and pale type can disappear when a marketplace reduces the image.

Export a draft, view it at approximately the size it will appear on a phone and ask someone unfamiliar with the item what they understood. If they must zoom to read the main message, shorten the copy or enlarge it. Inspect the uploaded image as well: compression and a different screen can change readability.

Measure before adding callouts

Measure the actual product with a suitable ruler or tape, and record width, height and depth with units. Identify whether a measurement includes handles, a lid or other protrusions. For a set, specify which piece is measured. Check each number against the source notes before placing arrows; perspective in a photograph is not a reliable way to calculate exact dimensions.

Put arrow endpoints at the measured boundaries and keep labels clear of one another. Where useful, include both metric and imperial units using accurate conversions and sensible rounding. A scale photo can complement measurements, but familiar objects vary in size and should not replace the numbers.

Use comparisons responsibly

A comparison chart can distinguish your own variants or show which included components come with each option. Label the columns and rows plainly and make sure every cell is accurate for the offer. Avoid competitor names and unsupported suggestions that another product is inferior. A chart is useful only if a buyer can tell exactly what is being compared.

Every claim must be true and substantiated. Keep the underlying test, certification or other evidence with your product records, and use the precise scope that evidence supports. Do not invent ratings, awards, certifications or results. Avoid prohibited badges and marketplace-style endorsement marks; check current rules before using any symbol or certification reference.

Final review checklist

  • Does each image answer one question without obscuring the item?
  • Are measurements, quantities, variants and units checked against the actual offer?
  • Can the main message be read on a phone without zooming?
  • Are claims supported, and are props or accessories clearly distinguished from included items?
  • Have you checked the current marketplace and category rules and kept the original files?
